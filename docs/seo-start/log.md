# Журнал SEO-работ

## 19 августа 2026 — пункт 1: canonical URL и устранение технических дублей

**Статус: реализовано, ожидает проверки после деплоя.**

- Выбран и закреплён предпочтительный формат адресов: `https://skinetics.ru` без `www` и без завершающего слеша.
- В корневые метаданные добавлен `metadataBase: https://skinetics.ru`.
- Self-canonical добавлен для главной, `/catalog`, `/serum`, `/about`, `/contacts` и всех актуальных товарных страниц.
- Товарные URL формируются из единого списка актуальных товаров; неизвестный slug теперь возвращает серверный `404`, а не `200` с клиентским перенаправлением в каталог.
- Явно задана политика Next.js `trailingSlash: false`.
- Локальная production-проверка подтвердила: целевые URL отдают `200` и собственный canonical, URL несуществующего товара — `404`, вариант товарного URL со слешем — `308` на вариант без слеша.
- Production-проверка после деплоя остаётся обязательной: нужно убедиться в raw HTML, HTTP-кодах и canonical по `https://skinetics.ru`.

## 19 августа 2026 — пункт 2: основной контент в исходном HTML

**Статус: реализовано, ожидает проверки после деплоя.**

- Найдена причина отсутствия контента в raw HTML: корневой `Suspense` охватывал все страницы вместе с клиентским `UTMProvider`, который вызывал `useSearchParams()`. При статической генерации Next.js переносил весь этот участок в клиентский рендер.
- Глобальная клиентская граница удалена: контент маршрутов снова рендерится сервером в HTML.
- Логика UTM перенесена к кнопкам Wildberries: до гидратации они используют стандартные метки, а параметры `utm_*` из адресной строки применяются в браузере после загрузки JavaScript.
- Локальная production-проверка подтвердила: raw HTML для `/`, `/catalog`, `/serum`, `/about` и `/catalog/red_pepper` содержит соответствующий H1; главная, каталог и `/serum` также содержат все три внутренние ссылки на товарные страницы.
- Production-проверка после деплоя остаётся обязательной: проверить те же URL без JavaScript, затем выполнить «Проверку страницы» в Яндекс Вебмастере.

## 19 августа 2026 — пункт 3: автоматически формируемый sitemap

**Статус: реализовано, ожидает проверки после деплоя.**

- Ручной `public/sitemap.xml` удалён и заменён маршрутом Next.js `app/sitemap.ts`, который формирует `/sitemap.xml` при сборке.
- Статические индексируемые страницы перечислены в одном месте: `/`, `/catalog`, `/serum`, `/about` и `/contacts`.
- Товарные URL формируются из `items` — единого списка актуальных карточек каталога. Поэтому удалённый из этого списка товар не попадёт в sitemap, а добавленный попадёт автоматически.
- В sitemap не указывается `lastmod`: у проекта нет подтверждённых дат содержательного обновления страниц, поэтому прежние фиктивные даты и частота обновлений удалены.
- Страница `/ingredients` намеренно не включена: сейчас это заглушка без полноценного индексируемого контента.
- Production-проверка после деплоя остаётся обязательной: проверить, что `/sitemap.xml` отдаёт 200, содержит восемь ожидаемых canonical URL и успешно обработан Яндекс Вебмастером.

## 19 августа 2026 — пункт 4: точечная доработка title и description

**Статус: реализовано, ожидает проверки после деплоя.**

- Для `/catalog` добавлены уникальные title и description, отражающие текущий ассортимент и активные компоненты в карточках.
- Перепроверены главная, `/serum`, `/about`, `/contacts` и три товарные карточки: каждому целевому URL заданы уникальные title и description.
- Из метаданных удалены неподтверждённая локальная привязка к Москве, обещание доставки с сайта и консультации трихолога. Сниппеты отражают фактическую воронку: знакомство со средством на сайте и переход к покупке на Wildberries.
- Метаданные товарных страниц теперь описывают состав и формат ухода, а не повторяют общие ключевые слова или рекламные обещания. Содержательные утверждения в основном тексте карточек остаются предметом отдельного пункта 5.
- `/ingredients` остаётся заглушкой без полезного для поиска контента. Для неё задан `noindex`; уникальные title и description будут добавлены вместе с полноценной страницей ингредиентов. Маршрут по-прежнему не включается в sitemap.
- Production-проверка после деплоя остаётся обязательной: для всех восьми URL из sitemap проверить raw HTML на title, description и canonical; для `/ingredients` — наличие `noindex`.

**Статус: кодовая часть реализована; документальная сверка перед публикацией обязательна.**

- Проведена инвентаризация утверждений в трёх карточках товаров, описаниях ингредиентов и общих текстах сайта; подробная таблица и список необходимых подтверждений сохранены в `docs/seo-analisys/claims-audit-001.md`.
- Из публичных карточек удалены заявления о лечении и профилактике заболеваний, гарантированном результате, предотвращении выпадения и седины, воздействии на фолликулы и клетки, «доказанной эффективности» и абсолютной безопасности.

- Справочные описания ингредиентов не менялись: это отдельный материал, а не текст товарных обещаний. Маршрут `/ingredients` по-прежнему `noindex` и не входит в sitemap.
- До публикации необходимо сверить состав, способ применения и предупреждения с актуальной этикеткой каждого SKU, а для будущих заявлений о свойствах получить подтверждающие документы и согласование ответственного за маркировку/рекламу.
