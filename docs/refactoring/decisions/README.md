# Decision records

Create a decision record when a choice:

- affects more than one phase;
- changes public URLs, product identity, analytics contracts, or content policy;
- is costly to reverse;
- resolves a documented disagreement between sources.

Use [the decision template](../templates/decision-record.md) and the next zero-padded identifier:

```text
0001-canonical-cream-brand.md
0002-product-url-policy.md
```

Do not create a decision record for routine implementation details that are already covered by an approved phase plan.
