# Cream application and precautions

Date: 2026-08-23
Status: Approved by product owner for both products

## Purpose

This record provides the product-owner-approved Russian wording for the two initial face creams. It is not manufacturer evidence and must be rechecked if current packaging, the declaration, or manufacturer documents contain different or additional instructions.

The same wording is used for both products because no verified product-specific difference is currently known. The product owner approved it separately for Ultra Lift and ReneWal on 2026-08-23.

## Approved wording

### Neon Beard Ultra Lift, 100 г

**Способ применения**

Нанесите небольшое количество крема на предварительно очищенную сухую кожу лица, избегая области вокруг глаз. Равномерно распределите лёгкими массажными движениями до полного впитывания. Используйте утром и/или вечером.

**Меры предосторожности**

Только для наружного применения. Возможна индивидуальная непереносимость компонентов. Избегайте попадания средства в глаза; при попадании тщательно промойте их водой. При появлении раздражения прекратите применение.

### SkineticsLab ReneWal, 50 г

**Меры предосторожности**

## Drafting basis

- The Phase 00 marketplace review supports morning/evening use context but does not provide authoritative application or precaution wording.
- Existing serum precautions were used only to identify neutral concepts. Scalp-specific wording, symptom guidance, and statements about medical consultation were not copied.
- No storage conditions, age restrictions, patch-test requirement, pregnancy guidance, frequency limit, or formula-specific incompatibility was invented.
- Article 5, section 9.2 of [ТР ТС 009/2011](https://eec.eaeunion.org/upload/medialibrary/3ee/TR-TS-Parfum.pdf) identifies special precautions when necessary and application information whose absence could lead to incorrect use as labeling information. This draft is not a regulatory compliance assessment.
