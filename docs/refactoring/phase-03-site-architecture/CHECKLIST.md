# Phase 03 checklist

## Research

- [ ] Review Phase 00 search-query and URL findings.
- [ ] Collect real marketplace questions and review themes.
- [ ] Inventory current and planned product, brand, ingredient, and expert content.
- [ ] Identify user journeys by concern, product type, brand, and ingredient.

## Architecture

- [ ] Confirm Skinetics portfolio positioning.
- [ ] Propose and compare 2–3 architecture approaches.
- [ ] Define the final page hierarchy.
- [ ] Define URL patterns and preservation rules.
- [ ] Define header, footer, mobile, and breadcrumb navigation.
- [ ] Define hub-and-spoke and cross-section internal links.
- [ ] Define indexation rules for unfinished or thin pages.

## Content system

- [ ] Define requirements for home, listing, product, brand, concern, ingredient, expert, about, and contact pages.
- [ ] Prioritize the first content cluster from measured demand.
- [ ] Specify authorship, review, evidence, and update-date requirements.
- [ ] Map each page to a conversion action and success metric.

## Migration and validation

- [ ] Produce the URL map and redirect specification.
- [ ] Check for orphan pages and excessive depth.
- [ ] Review architecture against current sitemap and search evidence.
- [ ] Obtain approval before Phase 04.
- [ ] Update root status and log.
