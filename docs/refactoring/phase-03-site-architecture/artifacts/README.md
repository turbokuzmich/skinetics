# Phase 03 artifacts

Store the approved site tree, URL map, navigation specification, content inventory, keyword/intent map, internal-link plan, and redirect matrix here.

- [Site tree and URL map](./site-tree-and-url-map.md) — canonical hierarchy, namespace rules, indexation states, and preservation policy for current and candidate paths.
- [Navigation and internal linking](./navigation-and-internal-linking.md) — launch navigation, canonical breadcrumbs, page-class adjacency rules, and click-depth proof.
- [Content map and page requirements](./content-map-and-page-requirements.md) — page-class purposes, evidence, conversions, metrics, content priorities, review rules, and publication gates.
- [Redirect matrix](./redirect-matrix.md) — explicit preserve treatment for every current canonical URL and rules for any future migration.
