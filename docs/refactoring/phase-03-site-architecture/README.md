# Phase 03 — Site architecture and content

- **State:** Complete
- **Owner:** Dmitry, business owner
- **Started:** 2026-08-23
- **Completed:** 2026-08-23

## Objective

Define a scalable, evidence-led site structure that lets visitors browse by brand, product type, concern, and ingredient while preserving existing search value.

## Prerequisites

- [x] Phase 02 local implementation validated
- [ ] Phase 02 production deployment and monitoring complete — tracked separately and does not block architecture documentation
- [x] Skinetics portfolio role accepted
- [x] Brand architecture accepted
- [x] Search-demand and URL baseline available
- [x] Initial cream and serum content questions collected

## In scope

- page hierarchy and navigation;
- brand, category, concern, ingredient, and expert-content hubs;
- URL patterns, breadcrumbs, and internal linking;
- content inventory and prioritized content map;
- indexation and redirect specifications.

## Out of scope

- final visual styling;
- mass article production;
- new direct-commerce functionality;
- unvalidated programmatic page generation.

## Deliverables

- approved site hierarchy and URL map;
- header, footer, breadcrumb, and contextual navigation specification;
- content inventory and prioritized topic map;
- internal-linking plan;
- URL preservation and redirect plan;
- page-template content requirements for Phase 04.

## Exit criteria

- [x] Every proposed indexable page has a user purpose and validated search or business demand.
- [x] Important products are reachable within three clicks.
- [x] Brand is not the only way to discover products.
- [x] Existing URLs have explicit preserve or migration treatment.
- [x] No orphan pages remain in the proposed structure.
- [x] Phase 04 has approved requirements for every page template.
