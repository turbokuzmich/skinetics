# Phase 00 artifacts

This directory contains the sanitized, reviewable Phase 00 evidence:

- [`product-evidence-index.md`](./product-evidence-index.md) — product identity, marketplace pairing, labeling evidence, and known gaps;
- [`marketplace-baseline.md`](./marketplace-baseline.md) — sanitized 90-day Wildberries product funnel and Ozon limitation;
- [`analytics-baseline.md`](./analytics-baseline.md) — installed analytics, current goals, and the no-traffic baseline;
- [`claims-audit.md`](./claims-audit.md) — risky current and dormant claims requiring removal, qualification, or review.

The accepted route inventory is maintained in [`shared/url-inventory.md`](../../shared/url-inventory.md). Search performance is recorded as unavailable because the site has no meaningful historical traffic; no numerical search baseline was invented.

Do not store credentials, customer-level data, or raw confidential seller exports.
