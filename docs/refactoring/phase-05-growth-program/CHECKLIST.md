# Phase 05 checklist

## Strategy and constraints

- [ ] Document team, owners, available hours, and monthly budget.
- [ ] Confirm the primary audience and highest-value product journeys.
- [ ] Confirm baseline traffic, marketplace CTR, and attributable-sales limitations.
- [ ] Select the first three growth bets and explicitly defer the rest.

## Foundation

- [ ] Define campaign naming and UTM conventions.
- [ ] Create weekly and monthly reporting templates.
- [ ] Build an experiment backlog with scoring criteria.
- [ ] Define content review and claims approval workflow.

## Initial growth bets

- [ ] Launch the first concern -> ingredient -> product content cluster.
- [ ] Test a two-cream comparison or selection experience.
- [ ] Test application/usage content linked from packaging or marketplace materials where permitted.
- [ ] Test a creator or expert distribution format.
- [ ] Run paid search or retargeting only if attribution and budget gates pass.

## Review loop

- [ ] Review leading indicators weekly.
- [ ] Review content and campaign results monthly.
- [ ] Stop, revise, or scale experiments using pre-agreed rules.
- [ ] Record customer and marketplace questions for the next content cycle.
- [ ] Complete the 90-day retrospective.
- [ ] Update root status and log.
