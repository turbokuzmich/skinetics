# Phase 04 inputs

- approved Phase 03 site architecture, URL map, and page requirements;
- approved brand architecture, logos, colors, typography constraints, and product photography;
- final or representative content for every template;
- trust assets such as manufacturer information, documentation, production imagery, and expert attribution;
- existing analytics and form requirements;
- browser/device support expectations;
- accessibility target;
- performance budgets;
- release and rollback constraints.

## Questions to answer before design approval

1. What should visitors feel about Skinetics in the first five seconds?
2. How visually independent should the three brands be?
3. Which single conversion action has priority on each page type?
4. Which trust evidence is available to show rather than merely claim?
5. Should the redesign ship template by template or as one coordinated release?
